# Axel Fernández Curros

**Desarrollo de software · Automatización · IA local · Videojuegos y creación digital**

Combino desarrollo de software, automatización e infraestructura para IA local con proyectos creativos. Mi formación incluye administración de sistemas en red, animación 3D, videojuegos y realidad virtual.

Aprendo construyendo, probando y documentando. También hago música y practico magia.

## Proyectos

- **[connect-core](https://github.com/Axlfc/connect-core)** — Plataforma modular de automatización e IA local con Docker Compose, n8n, Ollama, ComfyUI y Qdrant. En desarrollo.
- **[RuneScript](https://github.com/Axlfc/RuneScript)** — Editor y entorno de ejecución de scripts con integración de Git y funciones de IA.
- **[UE5-python](https://github.com/Axlfc/UE5-python)** — Experimentos de automatización con Python, Unreal Engine 5, Blender y HoudiniFX.
- **[get-winget](https://github.com/Axlfc/get-winget)** — Scripts para instalar y configurar Windows Package Manager desde la terminal.
- **[DST-Server-Docker](https://github.com/hypenosys/DST-Server-Docker)** — Configuración Docker para un servidor dedicado de *Don't Starve Together*, con instancias Master y Caves y soporte para mods.
