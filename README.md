# Axel Fernández Curros

**Software · Automatización · IA local · Videojuegos y 3D**

Trabajo entre el desarrollo de software, la administración de sistemas y la creación de experiencias interactivas. Mi formación abarca sistemas en red, animación 3D, videojuegos y realidad virtual. Me gusta construir herramientas, probarlas y documentar lo que aprendo.

## Proyectos

- **[connect-core](https://github.com/Axlfc/connect-core)** — Plataforma modular para integrar IA local y automatización con Docker, Ollama, n8n, ComfyUI y Qdrant. En desarrollo.
- **[RuneScript](https://github.com/Axlfc/RuneScript)** — Entorno de edición y ejecución de scripts con integración de Git y herramientas de IA.
- **[UE5-python](https://github.com/Axlfc/UE5-python)** — Experimentos con Python, Unreal Engine 5, Blender y herramientas de creación 3D.
- **[get-winget](https://github.com/Axlfc/get-winget)** — Scripts para instalar y configurar Windows Package Manager desde la terminal.
- **[DST-Server-Docker](https://github.com/hypenosys/DST-Server-Docker)** — Servidor dedicado de Don't Starve Together con Docker, mundos Master y Caves, y soporte para mods.

## Tecnologías y áreas

- **Sistemas y automatización:** Linux, Python, Bash, Docker, Git, PostgreSQL y Nginx.
- **Web y servicios:** HTML/CSS, TypeScript, Node.js, FastAPI y n8n.
- **IA local:** Ollama, PyTorch, Qdrant y ComfyUI.
- **Videojuegos y medios:** Godot, Blender, Unreal Engine, Unity y FFmpeg.

## Criterios de trabajo

Me importan la **privacidad**, la **accesibilidad** y el **uso responsable de los recursos**. Prefiero herramientas abiertas y sistemas que pueda desplegar y mantener, sin descartar soluciones propietarias cuando el contexto lo justifica.

Mantengo un [análisis personal de 84 herramientas y sus prácticas](https://usuaris.tinet.cat/~axlfc/). Es una valoración propia, no una certificación ni una clasificación universal.

Fuera del código también me interesan la música, los proyectos audiovisuales y la magia.
